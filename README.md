# 神羽 / Shenyu

> 神羽系列项目索引 · Shenyu series index
> 一个系列，而不是一个单一项目。

神羽是一个长期维护的个人开源系列，包含 Android 客户端、系统模块与实验性工具。  
本仓库只做**索引与共享文档**，各子项目在独立仓库中开发、发版、维护 Issue。

Shenyu is a long-term personal open-source series. This repository is the **index hub**; each project lives in its own repository with independent releases and issues.

## 系列约定 / Conventions

- 每个子项目独立仓库、独立版本号、独立 Release
- 共享文档放在本仓库 `docs/`（后续补充）
- 版本规则：功能中位 +1，修复末位 +0.1，单位满 10 进一
- 代码默认 MIT；各项目可在自己仓库声明额外资源许可
- 不包含任何官方 DeepSeek / 第三方商标素材
